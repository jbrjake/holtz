# Support

## Getting Help

**Bug reports and feature requests:** [GitHub Issues](https://github.com/jbrjake/holtz/issues).
Use the issue templates. Security issues go through
[private reporting](https://github.com/jbrjake/holtz/security/advisories/new),
not public issues.

**Questions and discussion:** [GitHub Discussions](https://github.com/jbrjake/holtz/discussions).
How to write a custom lens, how the convergence loop works, why Holtz flagged
something in your codebase, whether a pattern you're seeing is worth
generalizing — all good discussion topics.

**Not provided:** Real-time support, guaranteed response times, or support for
forked or modified versions. This is a single-maintainer open source project.
Responses happen when they happen.

## Before You Ask

- Check existing [issues](https://github.com/jbrjake/holtz/issues) and
  [discussions](https://github.com/jbrjake/holtz/discussions) — someone may
  have already asked.
- Read the [README](README.md) — it's thorough.
- Check the [docs/](docs/) directory for reference material on lenses, patterns,
  and the impact graph.

## What Version Are You Running?

Include the version and your Claude Code environment when reporting issues.
Check the version in `.claude-plugin/plugin.json`.
